# Telegram Bot (42 SHOP) — Каталог, Онлайн-Оплата FreeKassa, СДЭК и Админка

Полнофункциональный бот-магазин для Telegram с витриной товаров, приемом онлайн-оплаты через **FreeKassa** (СБП, Карты РФ, Криптовалюта), расчетом доставки через СДЭК, обработкой заказов администраторами, базой данных SQLite и вынесенными в JSON текстами.

---

## 💳 Настройка оплаты FreeKassa

1. Зарегистрируйтесь на сайте [FreeKassa](https://freekassa.net/) и создайте магазин в личном кабинете.
2. В настройках магазина скопируйте:
   - **ID магазина** (`FK_MERCHANT_ID`)
   - **Секретное слово 1** (`FK_SECRET_1`) — для создания ссылок на оплату.
   - **Секретное слово 2** (`FK_SECRET_2`) — для проверки уведомлений об оплате.
   - **API Ключ** (`FK_API_KEY`)
3. В настройках магазина в поле **Result URL (URL оповещения)** укажите адрес вашего сервера:
   ```
   http://ваш_ip_или_домен:8080/freekassa/result
   ```
   *(Метод отправки: POST)*
4. Внесите эти данные в файл [`.env`](file:///c:/Users/Lenovo/Desktop/electrionik%20tg%20bot/.env):
   ```env
   FK_MERCHANT_ID=12345
   FK_SECRET_1=ваш_секрет_1
   FK_SECRET_2=ваш_секрет_2
   FK_API_KEY=ваш_api_ключ
   WEBHOOK_PORT=8080
   ```
